## 👋 About Me

포트폴리오 : https://web-portfolio-nu-rosy.vercel.app/

안녕하세요. **사용자 흐름과 시스템 구조를 함께 설계하는 PM형 소프트웨어 개발자 이주호입니다.**

단순히 기능을 구현하는 개발자가 아니라, **왜 이 서비스를 만들어야 하는지와 어떤 방식으로 만들어야 하는지**를 함께 이해하는 개발자를 지향합니다. 사용자 경험, 서비스 목적, 기술적 가능성과 개발 현실성을 함께 고려해 아이디어를 실행 가능한 제품으로 바꿉니다.

프로젝트를 시작할 때 어떤 기술을 사용할지보다 **어떤 문제를 해결하는지, 사용자가 어떤 가치와 편리함을 얻는지, 팀이 현실적으로 구현할 수 있는지**를 먼저 고민합니다. 문제와 사용자의 필요를 정의한 뒤 기능의 우선순위를 정하고, MVP로 구현할 수 있는 범위부터 설계합니다.

아이디어를 서비스 흐름으로 구조화하고, MVP를 빠르게 구현한 뒤 발표와 사용자 피드백을 통해 개선합니다. 협업 과정에서는 역할과 책임을 명확히 하고 필요한 부분을 적극적으로 소통하는 것을 중요하게 생각합니다.
