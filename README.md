## 👋 About Me

안녕하세요. **사용자 문제를 서비스로 구조화하고 구현하는 개발자 이주호입니다.**
저는 Web / App / Data / AI 프로젝트를 중심으로 아이디어를 실제 동작하는 제품으로 만드는 경험을 쌓고 있습니다.

단순히 기능을 구현하는 것보다, **누가 어떤 문제를 겪고 있는지 정의하고, 그 문제를 해결할 수 있는 흐름과 기능을 설계하는 것**에 관심이 많습니다.
의료, 교육, 문학 관광, 건강 관리, 외국어 학습처럼 실생활과 연결된 주제를 바탕으로 서비스를 기획하고 개발해왔습니다.
